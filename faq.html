A few common questions about Hamax Downloader.

What is Hamax?

Hamax is a Windows desktop application designed to make media downloading simple and straightforward.

Is Hamax free?

The Hamax application is designed to be free to use.

Which formats are supported?

Hamax currently supports MP4, MKV, WebM and MP3 output options.

Can I queue multiple downloads?

Yes. You can add additional URLs while another download is running.

Can I pause a download?

Yes. Hamax supports pausing and resuming an active download.

Where are downloaded files saved?

You can choose your preferred save location in the application.
